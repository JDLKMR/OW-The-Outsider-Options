# Outer Wilds - The Outsider Options
An Outer Wilds mod that offers more options for use alongside The Outsider mod.

- **Respect Time Freeze Settings**: Time freeze is no longer forcefully disabled when reading the ship log and Nomai text, with the exception of the end of the loop as usual.
- **Disable Custom Ending**: Disables The Outsider's custom ending sequence.

Works fine if The Outsider is disabled, and just does nothing.
